    How the pieces fit

    Three traits in contracts.rs say what a stack, a queue and a dictionary must do. Seven types implement them. The demo and the tests only call trait methods, so the same code drives every implementation, and a mistake in one shows up as a difference from the others.

    src/main.rsdemonstrate::<S, Q, D>() runs one script per set of types: standard library, manual nodes, and the HashMap dictionary.
    tests/behavior.rsGeneric scenarios, stamped out per type by suite! and dictionary_suite!, plus a 1,000-step comparison across implementations.
    call only trait methods
